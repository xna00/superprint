# 超人打印（SuperPrint）

> 微信里转发文件，打印机直接出纸——不用装 App、不用登录电脑、不换聊天软件。

## 产品简介

超人打印是一套基于微信生态的云打印服务。部署方只需在一台连接打印机的 Windows 电脑上安装常驻代理，机构成员或家庭成员用微信扫描打印机二维码完成一次绑定，之后就能在企业微信客服会话里直接转发文档或图片，远程打印到指定打印机。

整个过程无需 U 盘、无需登录电脑、无需安装任何打印 App——微信人人都有，绑定即用。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 微信扫码绑定 | 扫打印机二维码进入客服会话即完成绑定，支持多用户绑多台打印机 |
| 聊天内直接打印 | 在微信/企业微信客服会话中转发文件即可发起打印，无需跳转其他应用 |
| 多格式支持 | PDF、Word、Excel、PPT、图片，全格式覆盖 |
| 多文件合并 | 待确认期间连续转发的文件自动并入同一任务，一单打完 |
| 打印设置 | 双面/单面、长边/短边翻页，可在任务详情页修改 |
| 任务详情 | H5 页面查看文件清单、预览 PDF、切换打印机、保存并打印 |
| 自动确认 | 60 秒无操作自动确认，人不在也能按时出纸 |
| 结果通知 | 打印完成、失败实时推送，失败文件可一键重试 |

## 适用场景

**家庭**：孩子作业、老师发在群里的试卷，长按消息转发即打印，老人小孩都会用。

**移动办公**：人在外面、文件在手机里，随时把文件打回办公室/家里的打印机。

**机构增值**：多用户多打印机统一管理、私有部署；附带公文识别（识别文号、标题并套红头模板生成 docx）、PDF 转换、PDF 转 Word 等文档服务。

## 为什么选它

- **人人有微信，零学习成本**：绑定 + 转发就是全部操作，无需下载、注册或配置
- **信息不换生态**：从"群里收到作业"到"打印机出纸"全程留在微信里，省去文件反复存取跳转
- **对比更轻**：无需像云打印机那样装各家小程序，无需像 U 盘那样登录电脑，无需像传统网络打印那样配 IP 和驱动

## 产品形态

私有部署、自带自动更新与安装/卸载流程，交付即可用，持续迭代。
